# Telegram Mini App для барбершопа

Готовый фронтенд мини-приложения: выбор услуги, мастера, даты/времени и отправка заявки в бота через `Telegram.WebApp.sendData`.

## Как запустить

1. Залейте папку `telegram-mini-app` на любой статический хостинг (Netlify/Vercel/GitHub Pages).
2. В `@BotFather`:
   - `/newapp`
   - Укажите URL на `index.html`.
3. В коде бота обработайте `web_app_data` и сохраните JSON в CRM или Google Sheets.

## Что уже есть

- Адаптация под тему Telegram (`--tg-theme-*`).
- Валидация обязательных полей.
- Локальный режим (если открыть в обычном браузере).
- Готовый payload для передачи в бот.
